# 首页背景 2.5D 景深设计

## 目标

在不更换首页水墨背景、不改变内容布局的前提下，为日间、夜间和移动端首页背景增加类似苹果壁纸的静态景深与轻量分层视差。

成功标准：

- 远景轻微虚化，中景和近景逐步清晰。
- 桌面端背景平滑跟随鼠标，移动端在浏览器直接提供方向数据时跟随设备倾斜。
- 视觉强度采用已确认的 B「平衡景深」，效果明确但不抢头像、标题和导航的注意力。
- 保留现有头像视差、雨效、日夜主题和移动端构图。
- 减少动态效果、无方向数据或脚本不可用时仍能看到完整静态背景。

## 已确认的产品边界

- 复用现有背景图片，通过 CSS 柔边蒙版形成远景、中景和近景，不制作新的透明分层图片。
- 不使用 Three.js、Canvas、WebGL 或新增运行时依赖。
- 不申请陀螺仪或方向传感器权限，不增加授权按钮。
- 不修改首页头像视差的输入和状态逻辑。
- 不改变雨效密度、首页文字、链接、按钮或整体排版。
- 不把效果扩展到首页以外的页面。

## 组件结构

新增客户端组件 `app/components/HomeBackgroundDepth.tsx`，由 `app/page.js` 在首页 `section.profile--rainy-mask` 内渲染。

组件只负责背景和输入控制，结构包含四个装饰层：

1. 完整背景层：保证蒙版或脚本不工作时画面仍完整。
2. 远景层：天空、云雾和远山，位移最小并轻微虚化。
3. 中景层：中距离山体和湖面，位移居中并保留少量虚化。
4. 近景层：两侧山石、树木和靠近画面底部的景物，保持清晰且位移最大。

组件使用 `aria-hidden="true"` 和 `pointer-events: none`，不进入读屏内容和交互顺序。现有雨层保持在背景上方、头像和页面内容下方。

首页原有 `body:has(.profile--rainy-mask)` 背景图片继续作为无组件或旧浏览器环境的后备画面。景深组件覆盖其上，但不会移除后备规则。

## 输入与数据流

所有输入被归一化为 `x`、`y` 两个 `-1` 到 `1` 的值，再写入组件根节点的 CSS 自定义属性。背景层只通过 `transform` 和 `filter` 响应这些变量，不触发 React 高频重渲染。

### 桌面鼠标

- 只在支持精确指针的设备上监听窗口级 `pointermove`。
- 使用指针相对视口中心的位置计算 `x`、`y`。
- 指针离开文档或窗口失焦后平滑回到中心。
- 输入经过 `requestAnimationFrame` 合并和平滑，避免背景抖动。

### 移动端方向数据

- 监听浏览器直接提供的相对 `deviceorientation` 事件，但不调用 `requestPermission()`。
- 首个有效姿态作为中点，避免要求用户水平持机。
- 屏幕旋转后清空基准并重新校准。
- 浏览器不提供方向数据时保持静态景深，不显示错误或权限提示。

### 生命周期

- 页面隐藏、组件不可见或窗口失焦时停止动画并回正。
- 卸载时移除所有监听并取消待执行动画帧。
- 复用现有 `home-avatar-parallax.ts` 中的坐标归一化、方向换算和平滑计算，避免产生第二套不一致的数学规则；头像组件本身不改动。

## 视觉参数

采用 B「平衡景深」：

- 远景位移：约 2–3px，方向与近景轻微相反。
- 中景位移：约 6–7px。
- 近景位移：约 10–12px。
- 远景模糊：约 1.8px。
- 中景模糊：约 0.55px。
- 近景：保持清晰。
- 所有图片层放大约 3%–5%，为移动留出安全余量，任何方向都不能露出画面空白。
- 柔边蒙版必须覆盖交叠区域，不能出现硬切边、重复轮廓或移动裂缝。
- 允许非常轻的边缘暗角帮助聚焦中心，但不能改变现有水墨色调。

头像继续使用自己的局部视差。背景使用视口级输入和更低速度，两者不共享 DOM 状态，也不互相阻塞；背景位移必须明显弱于头像的局部立体感。

## 日间、夜间和响应式构图

- 桌面日间继续使用 `home-ink-landscape.webp/png`。
- 移动端日间继续使用 `home-mobile-ink-bg.webp/png`。
- 夜间继续使用 `home-night-ink-bg.webp/png`，移动端保持现有裁切策略。
- 日间和夜间分别设置蒙版与明暗参数，不能假设两张图片的山体边界完全一致。
- 移动端单独校准蒙版和位移上限，避免窄屏裁切后近景移动过大。
- 主题切换只改变 CSS 可见层和图片资源，不重建输入监听。

## 动效与无障碍

- `prefers-reduced-motion: reduce` 下所有层取消位移和回正动画，只保留远、中、近的静态清晰度差异。
- 不增加自动循环的大范围背景运动。
- 不使用会造成明显眩晕的旋转、缩放呼吸或快速亮度变化。
- 景深层始终是装饰内容，不添加无意义的图片替代文本。
- 输入失败、方向字段缺失或计算得到非有限值时直接回到中心状态。

## 性能与降级

- 不新增网络图片请求种类；重复图层复用同一资源 URL 和浏览器缓存。
- 每帧只更新 CSS 自定义属性，动画属性限制为 `transform`、少量静态 `filter` 和蒙版。
- 页面不可见或组件不在视口时停止帧更新。
- 无 JavaScript时，服务端输出的完整背景层仍显示；不支持 CSS 蒙版时只显示完整背景层。
- `will-change` 仅用于实际移动的背景层，不能扩展到整个页面内容。

## 测试与验收

### 自动化测试

- 组件结构：完整、远景、中景和近景层均存在，且为装饰内容。
- 输入行为：鼠标中心、四个方向、离开回正和窗口失焦。
- 方向行为：首帧校准、屏幕旋转、无效数据和卸载清理。
- 降级行为：减少动态效果、无精确指针、无方向事件和无 CSS 蒙版后备。
- 样式约束：位移范围、模糊参数、图片安全放大、日夜资源、移动端资源和层级顺序。
- 回归检查：现有头像视差和雨效测试继续通过。

### 工程验证

- 运行首页背景、头像和雨效相关测试。
- 运行完整测试集。
- 运行类型检查。
- 运行生产构建。

### 浏览器验收

- 1440px 日间和夜间：移动平滑，无边缘空白、蒙版裂缝或文字可读性下降。
- 846px 日间和夜间：背景层级稳定，Header 和首页内容不抖动。
- 390px 日间和夜间：移动端构图不偏移，方向数据不可用时静态背景正常。
- 减少动态效果：背景完全不移动，静态景深仍存在。
- 快速移动鼠标、切换标签页和切换主题：无跳变、残留动画帧或控制台错误。

## 非目标

- 不生成真实三维几何或推测图片看不到的侧面。
- 不替换、重新绘制或生成新的首页背景图。
- 不让用户配置景深强度。
- 不实现滚动视差、页面转场或音效。
- 不重构现有头像视差组件。
