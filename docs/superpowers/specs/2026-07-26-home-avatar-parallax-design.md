# 首页头像 2.5D 视差设计

## 目标

在不改变首页水墨视觉、不新增图片资源、不引入 Three.js 的前提下，把现有头像改造成轻量 2.5D 视差场景。

成功标准：

- 桌面端头像平滑跟随鼠标，最大倾斜约 6°。
- 移动端优先使用浏览器直接提供的方向数据，否则使用触摸视差。
- 不主动申请陀螺仪或方向传感器权限。
- 保留日间默认图、桌面 Hover 表情图和夜间图。
- 降级环境始终能看到完整静态头像。
- 不破坏首页布局、圆形裁切和现有日夜主题。

## 已确认的产品边界

- 使用 CSS 柔边蒙版分层，不制作新的透明分层图片。
- 不使用 Three.js、Canvas 或 WebGL。
- 不显示陀螺仪授权按钮。
- 不在首次点击头像时触发系统权限弹窗。
- Android 等无需显式授权且能直接产生方向事件的浏览器可自动启用倾斜视差。
- iPhone Safari 无权限时使用触摸视差，不尝试绕过浏览器限制。
- `prefers-reduced-motion: reduce` 下关闭视差和呼吸动画。

## 组件结构

新增客户端组件 `app/components/HomeAvatarParallax.jsx`，由首页服务端组件负责渲染。

组件保持现有可聚焦头像容器和无障碍名称，内部包含三个视觉状态：

1. 日间默认状态。
2. 支持 Hover 的桌面表情状态。
3. 夜间主题状态。

每个状态重复使用对应原图，并通过柔边 CSS 蒙版形成三个深度层：

- 背景层：圆框、山水和植物，移动方向与前景轻微相反。
- 中景层：睡猫和兔子，移动幅度居中。
- 前景层：探头黑猫，移动幅度最大。

原始完整图片始终作为底层存在。即使蒙版、脚本或方向事件不可用，头像仍能完整显示。

## 输入与数据流

组件把所有输入归一化为 `x`、`y` 两个 `-1` 到 `1` 的值，再通过 CSS 自定义属性驱动倾斜与分层位移。

### 鼠标

- 只在支持精确指针的设备上启用。
- 根据指针相对头像中心的位置计算坐标。
- 最大倾斜约 6°。
- 指针离开后平滑回到中心。

### 触摸

- 触摸头像时按触点位置计算视差。
- 触摸结束或取消时平滑回正。
- 触摸操作不产生权限请求。

### 设备方向

- 监听相对 `deviceorientation` 数据，但不调用 `requestPermission()`。
- 以收到的首个有效姿态作为中点，避免用户必须水平持机。
- 对输入限幅和平滑，过滤传感器抖动。
- 若浏览器不发送方向数据，组件无错误地继续使用触摸输入。
- 页面卸载或组件停用时移除监听。

### 空闲状态

- 粗指针设备且未发生交互时允许非常轻微的呼吸动画。
- 一旦收到触摸或方向输入，实时输入优先。
- 减少动态效果模式下不启用空闲动画。

## 视觉参数

- 整体倾斜上限：约 6°。
- 背景位移：约 2–3px，方向与前景相反。
- 中景位移：约 4–5px。
- 前景位移：约 8–10px。
- 所有状态使用柔边蒙版，避免硬裁切边缘。
- 所有位移都限制在圆形裁切内部，不允许暴露画面空白。
- 回正和状态切换使用现有首页偏柔和的缓动节奏。

日间默认图、Hover 图和夜间图构图不同，因此分别设置蒙版中心和范围，不能共用一套坐标。

## 状态与主题

- 默认显示日间基础状态。
- 只有真正支持 Hover 的设备才切换到表情状态，避免触屏出现粘滞 Hover。
- 夜间主题继续由现有 `body.dark` 选择器控制，优先于日间和 Hover 状态。
- 主题切换只改变可见状态，不重建事件监听。

## 性能与降级

- 不新增运行时依赖、图片文件或独立资源 URL；重复图层复用现有三个图片地址及浏览器缓存。
- 使用 `requestAnimationFrame` 合并高频输入更新。
- 仅更新 CSS 自定义属性，避免 React 在每次移动时重新渲染。
- 使用 `will-change` 仅标记头像内部活动层。
- 组件不可见、页面隐藏或卸载时停止动画更新。
- 无 JavaScript、无方向数据、无 Hover、减少动态效果模式均保留静态头像。

## 无障碍

- 保留头像容器现有的可访问名称。
- 视觉分层继续设为装饰内容，不让读屏重复朗读图片。
- 减少动态效果用户看到完全静态的头像。
- 不添加隐藏按钮或不可理解的权限触发区域。

## 测试与验收

### 自动化测试

- 纯计算测试：中心值、四个方向、边界限幅和无效输入。
- 组件测试：鼠标移动、离开回正、触摸移动、触摸结束。
- 方向事件测试：首帧校准、输入平滑、缺失字段和卸载清理。
- 降级测试：减少动态效果、无方向事件、无 Hover。
- 样式测试：三层蒙版、日间/Hover/夜间显示规则、圆形裁切和移动端尺寸。
- 现有首页头像测试随新结构更新，继续检查三张原图均被使用。

### 工程验证

- 运行相关单元测试。
- 运行完整测试集。
- 运行类型检查。
- 运行生产构建。

### 浏览器验收

- 桌面亮色：鼠标跟随、Hover 表情、离开回正。
- 桌面暗色：只显示夜间状态并保持平衡视差。
- 手机亮色：触摸视差、空闲呼吸、无权限弹窗。
- 手机暗色：夜间图、触摸视差、尺寸无溢出。
- 减少动态效果：所有视差和呼吸停止。

## 非目标

- 不生成真实 3D 几何体。
- 不推测图片看不到的侧面。
- 不申请指南针、磁力计或绝对方向权限。
- 不增加可见的控制按钮、提示标签或授权入口。
- 不修改首页头像以外的视觉系统。
